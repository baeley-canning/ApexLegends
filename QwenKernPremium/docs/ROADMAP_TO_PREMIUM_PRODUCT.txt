PHASE 1 — PROVE THE RUNTIME FACTS (research -> measured truth)
--------------------------------------------------------------------------------
1.1 ACG/injection probe: tiny harness that, inside r5apex_dx12.exe, tries
    VirtualAllocEx(RWX), VirtualAllocEx(RW)+VirtualProtect(RX), PTE/NX path, and
    MDL mapping. Record which succeed per Windows build / HVCI on-off.
1.2 Injector strategy ladder in the launcher: try in the order
    A8 -> A7 -> A4 -> A3 -> A2 -> A1, log which succeeded, and make the choice
    sticky per machine. Never silently fall back without logging.
1.3 Reference integrity: assert game process name, module base, and that
    d3d11.dll is not force-loaded by us before the game uses it.
1.4 Offsets: run the dump pipeline (docs/APEX_OFFSETS_AND_DUMPING_METHODS.txt)
    against the live build; produce offsets.ini; wire OffsetValidator to read it.
1.5 Resolve the REAL view-matrix location (0x022EE01 is a code RVA): find the
    matrix via ViewRender/ViewMatrix chain from the dumped binary, then validate
    numerically (project known world points, expect plausible screen coords).
1.6 Validate entity offsets live: origin/team/health/bones; log the entity
    count and a few decoded players; freeze the numbers only after they match
    observed in-game positions.
GATE 1: written fact sheet with numbers + screenshots/logs; every offset marked
        PROVEN or CANDIDATE; injection ladder proven to reach a loaded DLL.

--------------------------------------------------------------------------------
RISK REGISTER (what actually kills this project)
--------------------------------------------------------------------------------
R1 Javelin changes the injection rules again (ACG-style)
   -> Phase 1's strategy ladder exists so re-testing is cheap; never hardcode
      one strategy.
R2 CR3 abuse / address-space relocation breaks attach-based reads
   -> implement B6(ii) physical + PML4 from the start.
R3 Driver denylist (#119) hits us or our loader chain
   -> multi-loader support + explicit detection/reporting.
R4 Offsets churn every patch
   -> automate dump + validate (Phase 1.4/1.6, Phase 8.1).
R5 Overlay hook causes stutter/crashes
   -> trampolines, full state save/restore, dual DX11/DX12 path, GATE 4.
R6 Behavioural bans from "perfect" aim
   -> humanised defaults, spectator-aware mode, honest presets.
R7 Scope creep (skins, spoofer, web radar)
   -> Phases 0-4 are the shippable core; 5-8 is the premium ring.
