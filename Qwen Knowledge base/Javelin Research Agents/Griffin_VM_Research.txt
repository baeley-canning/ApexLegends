1. OVERVIEW: GRAFFIN VM BY EA
================================================================================

Griffin is EA's in-house bin-to-bin (b2b) virtualizer that transforms native 
code into virtual machine bytecode. It's the core obfuscator used by Javelin 
anti-cheat to protect 20+ games including Apex Legends.

Key Characteristics:
- Creates new section (.grfn) to store virtualized code
- No handlers (unlike VMP/Themida)
- No virtual stack
- Uses Remill-style lifting for instruction translation
- MBA (Mixed Boolean-Arithmetic) folding applied on top

================================================================================
2. GRAFFIN VM ARCHITECTURE
================================================================================

Context Structure:
```c
struct Context {
    Register v_rax, v_rbx, v_rcx, ...;  // Virtual registers
    RFLAG v_rflag;                        // Virtual flags
    uintptr_t delta;                      // DLL base vs preferred address delta
};
```

Devirtualization Pipeline:
1. **Lift** - VM bytecode to LLVM IR
2. **Simplify** - Apply optimization passes
3. **Emit** - Generate clean native code

This is the same pattern used in the cheat's current Phase 1 implementation.

4. .GRFN SECTION FORMAT
================================================================================

The .grfn section is created during virtualization and contains:
- Virtualized bytecode
- Context structure layout
- Metadata for devirtualization

Key Properties:
- Section name: .grfn
- Contains all necessary information for VM execution
- No external handlers required
- Self-contained virtualization environment

5. MBA (MIXED BOOLEAN-ARITHMETIC) IN GRAFFIN
================================================================================

MBA folding is applied via LLVM on top of virtualized code:

Key Implementation Patterns:
- Linear MBA expressions obfuscated first
- Non-linear parts left as-is (easier to deobfuscate)
- MBA replaces simple arithmetic/logical operations with complex expressions
